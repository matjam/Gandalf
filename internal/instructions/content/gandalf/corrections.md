# Correction History

Why the rules say what they say.

This file is append-only and is **not** an instruction source. Nothing here is read at
session start, and nothing here overrides the operating contract or a topic. When a
correction produces a rule, the rule goes in the contract or the matching topic, where
it will actually be read; the reasoning stays here, where it does not have to be.

Keep entries short: what happened, what rule came out of it, and where that rule now
lives. The point is to stop the same argument from being had twice — six months later,
when the rule looks arbitrary and someone is tempted to remove it.

## Format

Newest entries last.

```
## YYYY-MM-DD — Short title

What happened, in a sentence or two. What rule it produced, and which file now
carries that rule.
```
