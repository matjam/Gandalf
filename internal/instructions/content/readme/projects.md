# Projects

One folder per project, work and personal alike.

| Note | Purpose |
|---|---|
| `Design.md` | Current state only. Delete superseded history rather than accumulating it. |
| `Decisions.md` | Append-only. Significant decisions with their context and accepted tradeoffs. |
| `Todo.md` | The durable backlog. Concrete items, with finished work moved to a completed section. |

Design notes go stale silently, which is the failure mode worth guarding against:
check the design note against reality before trusting it, and fix it when it is wrong.

Decisions notes are the opposite — they are allowed to be out of date, because they
record what was decided at the time and why. Do not rewrite an old entry when the
decision changes; add a new one that supersedes it.
