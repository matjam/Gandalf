# Standards

Engineering standards the agent applies when writing code. One file per topic; the
agent reads the ones the work touches rather than all of them every session.

These arrived as opinionated defaults so the vault does something useful immediately.
They are not a house style you have to adopt. Rewrite them to match how you actually
work — a standard you disagree with is worse than none, because the agent will follow
it.

Keep each file short enough to be read in full. A standard nobody finishes is a
standard nobody applies.
